architecture.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| native annotation files → converted sidecars | Malformed/attacker-controlled COCO-JSON, .txt, or box coords cross into the scorer |
| train split → test split | Leaked/duplicate images must not cross into the held-out test evaluation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-06 | Tampering | box coords out of image bounds during conversion | medium | mitigate | convert to half-open BBox at the boundary and clip via BBox.clipped_to; reject degenerate boxes loudly (labels._parse_sidecar already raises) |
| T-11-07 | Spoofing | evaluation inflated by train↔test leakage / duplicates | high | mitigate | dedup_fscd147 drops the 11 documented leaks + pixel-identical dups (file_sha256) before manifest construction; tests assert absence in test split |
| T-11-08 | Tampering | non-reproducible val carve masks a leak | high | mitigate | carve_val is deterministic np.random.default_rng(seed); test asserts seed-stability and that test is never touched |
| T-11-09 | Information disclosure | fabricated boxes from dot-only labels create false GT | medium | mitigate | D-06 enforced — dot-only annotations are skipped, never given synthesized boxes |
</threat_model>
