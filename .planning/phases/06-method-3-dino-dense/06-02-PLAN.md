  <action>
Module docstring: what it does, explicit pre/post-processing (deferring the ONNX numbers to the
inferencer docstring but stating the pooling/threshold/CC pipeline), known failure modes,
ROBUSTNESS BACKLOG.

`DinoDenseConfig` (frozen, Field descriptions): `scene_max_side: int = 1568` (the input-res cap),
`calibration: Literal["fixed","self-similarity","ratio","gmm"] = "gmm"`,
`threshold: float | None = None`, `min_component_area: int = 4`, `max_candidates: int = 50`,
`seed: int = 0`.

Numbered steps:
  # 1. Get the DINOv2 inferencer from app.state (or construct for CLI), reusing the ONE model.
  # 2. Embed the crop → mean-pool its patch tokens into a prototype; **L2-normalize** it.
  # 3. Run the scene at high resolution (capped at scene_max_side; **log when the cap engages**
       rather than silently downscaling a 6000px image to nothing), get its token grid,
       **L2-normalize** the grid.
  # 4. Cosine similarity = prototype · grid (both normalized) → a (gh, gw) map.
  # 5. Bilinearly upsample the **map** (not the tokens) to image resolution, using the scale
       factors the inferencer returned so it aligns to pixels.
  # 6. Calibrate the threshold via common.calibration.
  # 7. Threshold → `cv2.connectedComponentsWithStats`; **skip label 0** (background — emitting
       it is a full-image false positive), one box per remaining component above
       min_component_area.
  # 8. Sub-threshold candidates (EVAL-08): the top-N components/peaks with their raw similarity
       as score. Diagnostics: the similarity heatmap via viz.heatmap_png_b64.
  # 9. Register.

METHOD-12: connected components naturally returns many; never reduce to one.

Tests (model-free logic where possible): the L2-normalization order; label-0 skipping (feed a
synthetic labelled map); the upsample aligns a known token peak to the right pixel. Mark the
real-model end-to-end test to skip when the weight is absent.
