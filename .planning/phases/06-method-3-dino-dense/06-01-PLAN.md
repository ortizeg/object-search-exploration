  <files>src/object_search/inference/dinov2.py, tests/test_dinov2.py</files>
  <action>
`DINOv2Inferencer(ONNXInferencer)`. Docstring carries the **exact verified contract**: input
`pixel_values` f32 NCHW, fully dynamic; **RGB**; scale `1/255`; mean `[0.485,0.456,0.406]`; std
`[0.229,0.224,0.225]`; **bicubic**; **do NOT centre-crop**. Output `last_hidden_state`
`[B, floor(H/14)*floor(W/14)+1, 384]`; index 0 is CLS.

Use the base `ONNXInputSpec` with `resize="snap-to-multiple"`, `size_multiple=14`,
`interpolation="bicubic"`, and have preprocess **return the exact scale factors** used, because
token coordinates cannot be mapped back to image pixels without them (DINOv2 silently drops
trailing pixels when a side is not a multiple of 14 — a systematic offset, not an error).

`dense_tokens(image) -> (grid: NDArray[H//14, W//14, 384], scale_x, scale_y)`:
  - run the session
  - `_derive_layout(tokens, H, W)`: compute `gh = H//14`, `gw = W//14`, derive
    `n_register = tokens - 1 - gh*gw`, and **raise `ONNXContractError`** if `n_register < 0` or
    if a two-aspect-ratio probe disagrees. This is the INFRA-09 discipline: a silent spatial
    shift becomes a load-time error. `dinov2-small` has `n_register == 0`, but the slice is
    written as `[1 + n_register:]`, not `[1:]`, so a with-registers variant cannot silently
    shift the whole map.
  - strip the first `1 + n_register` tokens, reshape the remaining `gh*gw` **height-first** to
    `(gh, gw, 384)`.

**Prove the grid is not transposed (the highest-risk test):** use a **448×896** canvas (14·32 ×
14·64 — deliberately non-square) with a distinctive patch at roughly (row 42, col 700). Assert
the similarity peak (dot the target token against the grid) lands at the expected `(gy, gx)`,
and assert `gy != gx` and `gh != gw` so the fixture is **structurally incapable** of passing
under a transpose. Comment that a square image cannot detect a transpose and that a transposed
map renders as a perfectly reasonable heatmap. **Skip this test when the real weight is absent**
(mark it), but keep the `_derive_layout` arithmetic test model-free (feed it synthetic token
counts) so CI still gates the risky logic.
  </action>
