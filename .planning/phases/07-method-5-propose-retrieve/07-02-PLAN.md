  <action>
Module docstring: what it does, explicit pre/post-processing, known failure modes, ROBUSTNESS
BACKLOG. Note that this is the method Milestone 2 reuses.

`ProposeRetrieveConfig` (frozen, Field descriptions): `proposal_backend: Literal["fastsam"] =
"fastsam"`, `proposal_conf: float = 0.4`, `retrieval_threshold: float | None = None`,
`nms_iou: float = 0.5`, `max_candidates: int = 50`, `seed: int = 0`.

`embed_regions(image, boxes, config) -> NDArray` — the **second independently callable unit**:
crop each box, embed via the **same `DINOv2Inferencer`** as Method 3 (mean-pool tokens, then
**L2-normalize**), return one embedding per box. It does not know about proposals or exemplars.

`search()` — numbered steps that compose, and do nothing the units cannot do alone:
  # 1. propose(image, config) → proposals (the unit from 07-01)
  # 2. embed_regions(image, [p.box for p in proposals], config) → proposal embeddings
  # 3. embed_regions(image, [exemplar.box], config) → the exemplar embedding
  # 4. cosine NN = proposal embeddings · exemplar (all normalized) → scores. **Plain NumPy
       matmul — no FAISS** (pure dependency cost for a few hundred proposals; shape the store so
       FAISS slots in for corpus search later).
  # 5. calibrate/threshold; the accepted proposals become matches, the rest candidates (EVAL-08).
  # 6. **post-retrieval NMS** at nms_iou to collapse SAM over-segmentation (one object → several
       proposals). Record the proposal count in diagnostics.
  # 7. diagnostics carry the proposal set; latency attributes proposal vs embedding time
       **separately** (the proposal stage dominates — that is the finding EVAL-11 exists for).
  # 8. register.

Tests:
- **Seam test:** call `propose()` and `embed_regions()` **directly** (not through search) and
  assert each works standalone — Milestone 2 depends on this.
- **Reuse test:** assert `embed_regions` uses the same DINOv2 model instance/contract and that no
  second DINOv2 file is fetched (e.g. patch the fetch and assert it is not called for a second
  model key).
- Model-free where possible; skip real-inference assertions without the weights.
