# 1. Detect + describe on crop and scene (same backend)
Backend returns `(keypoints, descriptors)` where each keypoint carries `x, y` and **optional**
`scale`/`angle` (present for SIFT/AKAZE/ORB, would be None for a frameless backend). The
**distance metric is a property of the backend**: SIFT/AKAZE float L2, ORB Hamming.

# 2. Low-keypoint guard (METHOD-04c)
If exemplar keypoints < `min_exemplar_keypoints`, return `outcome=EMPTY` with a
`Diagnostics.notes` entry stating the crop lacks texture for this method — **never a silent
empty result**.

# 3. Many-to-many top-k matching — RATIO TEST DISABLED
For each crop keypoint, take its top-`k` scene neighbours **unconditionally** (no best/second
ratio). Optionally apply only the **k+1 ratio**: compare the k-th distance to the (k+1)-th and
drop the crop keypoint only if they are within `kplus1_ratio`. Record `k_ceiling_hit` in
diagnostics when the k-th neighbour is still strong (instances likely truncated).

**The counterfactual test (a success criterion):** build a scene with ≥6 near-identical textured
instances so each crop keypoint has several near-equal distances. Assert that the standard Lowe
ratio (best/second < 0.8) would drop the correspondences, while the k+1 path keeps them.

# 4. Vote in 4-DoF pose space
Bin widths (Lowe IJCV 2004 §7.3, verified): **30°** orientation, **factor 2** scale,
**0.25 × max projected crop dimension** location. The location bin width is **scale-dependent**,
so store votes in a **dict keyed by the bin tuple** (a hash table), not a dense array.

**Soft binning:** each vote lands in the 2 nearest bins per dimension — 16 bins per vote in
4-DoF. **θ wraps circularly**: a vote near 0°/360° must reach adjacent bins, not opposite ends.

Three voting modes (METHOD-04a):
  - `single-4dof` — SIFT/AKAZE/ORB only. One correspondence + its keypoint frame → a full
    similarity transform → a vote for the object centre. **Raise a clear error if the backend's
    keypoints have no scale/orientation (frameless).**
  - `translation-2dof` — any backend. Vote in (Δx, Δy) only.
  - `pairwise-4dof` — any backend. Each pair of correspondences → a 4-DoF similarity; sample
    pairs up to `pairwise_cap` (record the cap in diagnostics; it is O(n²)).

# 5. Enumerate peaks
Peaks are bins with ≥ `min_votes`, de-duplicated against the 3⁴ neighbourhood so adjacent bins
are not counted twice. Each peak carries its member correspondences.

Tests: a synthetic set of correspondences on a known translation produces one peak at the right
(Δx, Δy); a θ near 360° lands in the 0° neighbour bin (circular wrap); `single-4dof` on
frameless keypoints raises.

# 6. Per-peak RANSAC — NumPy, real seed
For each peak, fit a 4-DoF similarity from that peak's correspondences using RANSAC
**implemented in NumPy** with `rng = np.random.default_rng(config.seed)`. Do NOT use
`cv2.setRNGSeed` — it has no effect on OpenCV RANSAC (hardcoded `RNG rng((uint64)-1)` in
ptsetreg.cpp), so a config seed wired to it would be advertised and inert. From 2-point samples
a 4-DoF similarity is ~30 readable lines: sample 2 correspondences, solve for
(scale, rotation, tx, ty), count inliers within `ransac_thresh_px`, keep the best over
`ransac_iters`. Accept the peak if inliers ≥ `min_inliers`.
`cv2.estimateAffinePartial2D` may be used as an optional cross-check, documented as having a
fixed, non-configurable internal seed.

# 7. Degeneracy rejection — scale plausibility and mirror rejection
**NOT shear or aspect distortion** — a 4-DoF similarity has neither by construction, so those
tests are vacuous and can only ever pass. Reject instead on: implausible scale
(outside a configured range relative to the exemplar), and **mirror/reflection**
(negative determinant of the 2×2 linear part). Add a comment saying shear/aspect were
deliberately dropped as vacuous for 4-DoF, and would only become meaningful if a full affine
model is ever added as a config option.

# 8. Box mapping, exemplar self-match, result
Transform the exemplar box corners by the fitted model → axis-aligned scene box. Label the peak
whose box coincides (high IoU) with the exemplar as `is_exemplar=True` — a true instance, not a
duplicate. Keep sub-threshold candidates for EVAL-08 (peaks below the inlier threshold, with
their vote counts as scores). Assemble `Diagnostics` with correspondences and hough_peaks, and
the `LatencyBreakdown`. METHOD-12: never short-circuit to a single best match.

# 9. Register
`@register_method(name="sparse-geo", ...)`; add the import to `search/__init__.py`.

Tests: same seed → byte-identical matches; a **different** seed can produce a different sampling
order (proving the seed is real); a mirror-transformed correspondence set is rejected; the
exemplar self-match is labelled; a 6-instance scene returns multiple distinct models (METHOD-12).
